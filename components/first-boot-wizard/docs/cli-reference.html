💻 CLI Reference

Complete command reference for NubiferOS tools.

nubifer-workspace

Manage cloud workspaces with isolated credentials.

nubifer-workspace create
Create a new workspace
nubifer-workspace create \
    --name NAME \
    --provider {aws,azure,gcp,oracle,multi} \
    --account-id ACCOUNT_ID \
    [--account-name DISPLAY_NAME] \
    [--region REGION] \
    [--credential-id CRED_ID] \
    [--read-only]
nubifer-workspace list
List all workspaces
nubifer-workspace list [--provider PROVIDER]
nubifer-workspace switch
Switch to a workspace
nubifer-workspace switch WORKSPACE_ID_OR_NAME
nubifer-workspace current
Show current workspace
nubifer-workspace current
nubifer-workspace delete
Delete a workspace
nubifer-workspace delete WORKSPACE_ID
nubifer-workspace readonly
Set read-only mode
nubifer-workspace readonly WORKSPACE_ID --enable
nubifer-workspace readonly WORKSPACE_ID --disable
nubifer-workspace update
Update workspace settings
nubifer-workspace update WORKSPACE_ID \
    [--name NAME] \
    [--account-name NAME] \
    [--region REGION] \
    [--credential-id ID]
nubifer-workspace env
Export environment variables
eval $(nubifer-workspace env WORKSPACE_ID)

nubifer-creds

Manage encrypted cloud credentials. Credentials are bound to your active workspace.

nubifer-creds add
Add a new credential (prompts for workspace confirmation)
# AWS (short form)
nubifer-creds add -t aws -n NAME

# AWS (long form with all options)
nubifer-creds add --type aws --name NAME \
    [--access-key-id KEY] \
    [--secret-access-key SECRET] \
    [--region REGION] \
    [-w WORKSPACE_ID]  # Target specific workspace \
    [-y]               # Skip confirmation

# Azure
nubifer-creds add -t azure -n NAME \
    [--tenant-id ID] \
    [--client-id ID] \
    [--client-secret SECRET]

# GCP
nubifer-creds add -t gcp -n NAME \
    --project-id PROJECT \
    --key-file /path/to/key.json

# API Token
nubifer-creds add -t api -n NAME \
    [--token TOKEN] \
    [--scopes SCOPES]
nubifer-creds get
Retrieve credential values
# View credentials (secret is masked)
nubifer-creds get -t aws -n NAME

# Output as JSON
nubifer-creds get -t aws -n NAME --json
nubifer-creds list
List credentials in current workspace
nubifer-creds list [-t TYPE]
nubifer-creds remove
Remove a credential
nubifer-creds remove cloud/aws/my-account
🛡️ Security Note: Credentials are never exported to environment variables. The CLI wrappers (aws, az, gcloud) automatically retrieve credentials from the encrypted store using AWS credential_process and similar secure mechanisms.

nubifer-setup-wizard

Initial setup and configuration.

nubifer-setup-wizard setup
Run initial setup (default)
nubifer-setup-wizard
nubifer-setup-wizard setup
nubifer-setup-wizard backup
Backup GPG private key
nubifer-setup-wizard backup
nubifer-setup-wizard status
Show setup status
nubifer-setup-wizard status

Shell Shortcuts

Quick aliases available in your terminal:

nw              # nubifer-workspace
nw-switch NAME  # nubifer-workspace switch NAME
nw-context      # nubifer-workspace current
