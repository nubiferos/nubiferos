📦 Software Center

NubiferOS includes a curated Software Center with tools specifically chosen for cloud development and DevOps work.

Launching the Software Center

nubifer-software

Or find it in the Applications menu under "NubiferOS Software Center".

Available Categories

☁️ Cloud CLIs

  • AWS CLI v2 - Official Amazon Web Services CLI
  • Google Cloud SDK - GCP command-line tools
  • Azure CLI - Microsoft Azure CLI

☸️ Kubernetes

  • kubectl - Kubernetes command-line tool
  • Helm - Kubernetes package manager
  • k9s - Terminal UI for Kubernetes
  • Minikube - Local Kubernetes for development
  • eksctl - Amazon EKS cluster management

🏗️ Infrastructure as Code

  • Terraform - Infrastructure provisioning by HashiCorp
  • Pulumi - Modern IaC in any programming language
  • Ansible - Configuration management and automation

📦 Containers

  • Docker - Container platform
  • Podman - Daemonless container engine

✏️ IDEs & Editors

  • Visual Studio Code - Popular code editor
  • IntelliJ IDEA Community - Java/Kotlin IDE
  • PyCharm Community - Python IDE
  • Neovim - Hyperextensible Vim-based editor

🔧 DevOps Tools

  • GitHub CLI - GitHub's official CLI
  • ArgoCD CLI - GitOps continuous delivery
  • Trivy - Security scanner for containers and IaC

🗄️ Database Clients

  • PostgreSQL Client - psql and related tools
  • MySQL Client - MySQL command-line tools
  • Redis CLI - Redis command-line tools

🔐 Security Tools

  • KeePassXC - Offline password manager with local encrypted database
  • Bitwarden - Open source password manager with cloud sync
  • 1Password - Premium password manager for teams

Password Managers

NubiferOS uses pass (password-store) internally for cloud credential management. However, you may want a separate password manager for:

  • SSH keys and passphrases
  • API tokens for non-cloud services
  • Personal passwords and secure notes
  • Team credential sharing
💡 Recommendation: Use KeePassXC if you prefer fully offline, local-only storage. Use Bitwarden if you need cross-device sync. Both are open source and well-audited.

Installing via CLI

You can also install tools directly via apt or the official installers:

# Example: Install KeePassXC
sudo apt install keepassxc

# Example: Install Docker
sudo apt install docker.io docker-compose
sudo usermod -aG docker $USER

Requesting New Tools

If you need a tool that's not in the Software Center, you can:

  • Install it manually via apt or the official installer
  • Open an issue on GitHub to request it be added
