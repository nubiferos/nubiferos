🔐 Credential Management

NubiferOS uses GPG-encrypted storage via pass (password-store) to securely manage your cloud credentials.

🛡️ Security: Your credentials are encrypted with your GPG key and never stored in plain text. Even if someone gains access to your disk, they cannot read your credentials without your GPG passphrase.

Initial Setup

Before adding credentials, run the setup wizard:

nubifer-setup-wizard

This creates your GPG key and initializes the password store.

Adding Credentials

AWS Credentials

nubifer-creds add --type aws --name my-aws-account

You'll be prompted for:

  • AWS Access Key ID
  • AWS Secret Access Key

Azure Credentials

nubifer-creds add --type azure --name my-azure-account

You'll be prompted for:

  • Azure Tenant ID
  • Azure Client ID
  • Azure Client Secret

GCP Credentials

nubifer-creds add --type gcp --name my-gcp-project \
    --project-id my-project-123 \
    --key-file /path/to/service-account-key.json
💡 Note: The original key file is securely deleted after import. Your credentials are now stored encrypted in the password store.

API Tokens

nubifer-creds add --type api --name github-token

Listing Credentials

# List all credentials
nubifer-creds list

# List only AWS credentials
nubifer-creds list --type aws

Removing Credentials

nubifer-creds remove --id cloud/aws/my-aws-account

How It Works

Under the hood, NubiferOS uses:

  • GPG - Industry-standard encryption (same as used for email encryption)
  • pass - Unix password manager that stores each credential as a GPG-encrypted file
  • Workspace isolation - Credentials are organized by workspace

Storage Location

~/.password-store/nubifer/
├── default/
│   └── cloud/
│       ├── aws/
│       │   └── my-account/
│       │       ├── access-key-id.gpg
│       │       ├── secret-access-key.gpg
│       │       └── region.gpg
│       └── azure/
│           └── ...
└── workspace-name/
    └── ...

Backup Your Credentials

Backup GPG Key (IMPORTANT!)

nubifer-setup-wizard backup

This exports your GPG private key. Store it securely (encrypted USB, safe, etc.).

⚠️ Important: Without your GPG key, you cannot decrypt your credentials. Always keep a secure backup!

Backup Password Store

If you initialized git during setup:

# Add a remote repository
pass git remote add origin git@github.com:you/pass-backup.git

# Push your encrypted credentials
pass git push -u origin main

Direct Access via pass

You can also use pass directly:

# List all entries
pass

# Show a specific credential
pass show nubifer/default/cloud/aws/my-account/access-key-id

# Edit a credential
pass edit nubifer/default/cloud/aws/my-account/access-key-id
