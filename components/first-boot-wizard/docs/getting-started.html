🚀 Getting Started with NubiferOS

Welcome! This guide will walk you through the initial setup of your NubiferOS workstation.

Quick Setup (3 Steps)

1 Run the Setup Wizard

Open a terminal and run:

nubifer-setup-wizard

This will:

  • Generate a GPG key for encrypting your credentials
  • Initialize the password store (pass)
  • Optionally set up git for credential backup

2 Create Your First Workspace

A workspace isolates credentials for a specific cloud account:

nubifer-workspace create \
    --name my-project \
    --provider aws \
    --account-id 123456789012 \
    --account-name "My AWS Account"

Replace 123456789012 with your actual AWS account ID.

3 Add Credentials

Add your cloud credentials to the workspace:

nubifer-creds add --type aws --name my-project

You'll be prompted for your AWS Access Key ID and Secret Access Key.

Using Your Workspace

Switch to a Workspace

nubifer-workspace switch my-project

Or use the shortcut:

nw-switch my-project

Check Current Workspace

nubifer-workspace current

Or use the shortcut:

nw-context

List All Workspaces

nubifer-workspace list
💡 Tip: Your terminal prompt will show the active workspace and cloud provider icon, so you always know which account you're working with.

Re-run Setup Wizard

You can re-run the graphical setup wizard anytime:

  • Click "NubiferOS Setup" on your desktop
  • Or run: nubifer-welcome --force
