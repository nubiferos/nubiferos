🛡️ Security

NubiferOS is built with security as a core principle. Here's how your data is protected.

Security Layers

Defense in depth - multiple layers of protection:

🔒
Full Disk Encryption (LUKS)
All data encrypted at rest with AES-256
🔐
Credential Encryption (GPG)
Cloud credentials encrypted with your personal GPG key
📦
Workspace Isolation (Firejail)
Each workspace runs in a sandboxed environment
🛡️
Mandatory Access Control (AppArmor)
Kernel-level restrictions on application behavior
🔥
Firewall (UFW)
All incoming connections blocked by default
🚫
Intrusion Prevention (fail2ban)
Automatic blocking of brute force attempts
📝
Audit Logging (auditd)
All credential access is logged
🔄
Automatic Updates
Security patches applied automatically

What's Protected

✓ Protected Against:
  • Physical theft (disk encryption)
  • Credential theft (GPG encryption)
  • Cross-account mistakes (workspace isolation)
  • Keylogging (Wayland display server)
  • Malicious applications (AppArmor sandboxing)
  • Network attacks (firewall + fail2ban)
  • Brute force attacks (fail2ban + strong passwords)

Verify Security Status

Check that all security features are enabled:

sudo verify-security

Disk Encryption

Your entire disk is encrypted with LUKS (Linux Unified Key Setup):

  • Algorithm: AES-256-XTS
  • Key size: 512-bit
  • Status: Mandatory (cannot be disabled)

Credential Security

Your cloud credentials are protected by multiple layers:

  1. Encrypted with your GPG key (RSA 4096-bit or Ed25519)
  2. Stored in the password store (~/.password-store)
  3. On an encrypted disk (LUKS)

Best Practices

  • Backup your GPG key - Run nubifer-setup-wizard backup
  • Use read-only mode for production accounts
  • Rotate credentials every 90 days
  • Enable MFA on all cloud accounts
  • Keep system updated - Updates are automatic, but check periodically

Recovery Key

During installation, you received a LUKS recovery key. This allows disk access if you forget your password.

  • Store it in a physical safe or secure location
  • Never store it on the same computer
  • Test it periodically
